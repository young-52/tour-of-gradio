## 2. Colab에서 Gradio 설치

gradio는 웹 어플리케이션을 만들어주는 라이브러리입니다.

코드 셀에 `!pip install gradio`라고 입력하고 왼쪽의 실행 버튼▶️을 눌러주세요!

```bash
pip install --upgrade gradio
```

다음과 같은 멘트가 제일 아래에 출력되면 성공적으로 설치된 것입니다.

```text
Successfully installed gradio-6.6.0 gradio-client-2.1.0
```

## 3. Colab에서 Gradio 사용하기

이제 gradio 라이브러리가 설치되어서 gradio를 사용할 수 있어요.

간단한 코드를 작성해서 함께 실습해봅시다! 새로운 셀에 아래 코드를 작성해보아요.

```python
import gradio as gr

def greet(name):
    return f"Hello {name}!"

demo = gr.Interface(fn=greet, inputs="text", outputs="text")
demo.launch()
```

![그라디오 실행 화면](/images/colab-gradio.png)

동일하게 왼쪽의 실행 버튼▶을 누르면 위와 같은 화면이 출력돼요.

`* Running on public URL:` 에 적혀있는 링크를 클릭해 새 창으로 접속하여도 동일한 화면을 접할 수 있습니다.

이 코드는 이름을 입력했을 때, `“Hello {이름}!”`을 출력하는 간단한 코드입니다.
Gradio의 코드가 어떻게 이루어지는지는 다음 장의 Gradio 이론에서 조금 더 자세히 다루어 볼 거예요.

## 4. Colab에서 Gradio 원리 이해하기

그렇다면 이렇게 작성한 Gradio 코드와 Gradio 화면은 어떤 과정을 통해서 실현되는 걸까요?

단순히 짧은 Python 코드를 작성하는 것만으로도 새로운 URL이 생기고 name 작성 박스와 여러 버튼이 있는 화면이 출력되는 원리에 대해서 알아보도록 합시다!

이를 위해서는 Colab에 대한 간단한 이해가 필요한데요, **Colab은 Google의 임시 클라우드 서버(가상 컴퓨터)를 활용**해서 코드를 실행하는 환경입니다.

즉, 우리가 코드를 실행하면, 내 컴퓨터에서 실행되는 것이 아니라 Google의 컴퓨터(서버)에서 실행되는 거죠.

### 4.1 우리가 코드를 실행하면 생기는 일

아까 작성한 코드인

```python
demo.launch()
```

이 한 줄이 하는 일은 생각보다 많습니다.

이 코드가 실행되면,

1. Colab 서버 안에서 작은 웹 서버가 실행됩니다.
2. 그 서버에서 Gradio가 자동으로 웹 페이지를 만들어 줍니다.
3. 그 웹 페이지에 접속할 수 있는 주소(URL)가 생성됩니다.

정리하면 이런 흐름입니다.

```text
(1) 우리가 Colab에서 코드 실행
        ↓
(2) Colab 서버에서 Gradio 웹 서버 실행
        ↓
(3) 접속 가능한 URL 생성
        ↓
(4) 우리가 브라우저에서 접속
```

이런 과정을 거쳐서 우리가 작성한 코드가 웹사이트 형태로 실행되는 것이죠.
