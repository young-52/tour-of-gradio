## 1️⃣ Gradio는 어떤 도구일까?

### 과거에는 이런 문제가 있었어요 👇

- AI 모델은 연구자나 개발자만 사용 가능해요.
- 결과를 보려면 복잡한 코드를 실행해야 해요.
- 다른 사람에게 보여주려면 웹 개발을 따로 해야 해요.
- 데모를 만드는 데 며칠~몇 주가 걸려요.

Gradio는 이런 문제를 해결하려고 만들어졌습니다.

> 💡 AI를 연구실 안에 두지 말고, 누구나 브라우저에서 눌러보고 체험하게 하자.

즉,

- AI 접근성을 낮추고
- 실험 → 공유 → 피드백 → 개선 과정을 빠르게 만들기 위한 도구입니다.

### 그렇지만 단순히 AI 분야에서만 사용되는 건 아니에요

예를 들어 다른 사람들이 내가 만든 다음과 같은 기능을 사용해보길 원한다고 생각해봅시다.

```python
def print_hello(name): 
	return f"Hello, {name}!"

name = input()
print_hello()
```

그렇다면 다음과 같은 어려움이 발생할 수밖에 없어요.

- 코딩을 잘 모르는 사람은 이것이 무얼 하는 함수인지 모를 수 있어요.
- 함수를 실행할 수 있는 터미널 환경이 필요해요.
- 사용자가 직접 해당 코드를 실행하는 방법을 알아야 해요.

### 하지만 Gradio를 쓰면 이렇게 직관적으로 바뀌어요 👇

<HelloWorld />

- ✍️ **입력창**(텍스트, 이미지, 음성, 슬라이더 등)
- ▶️ **실행 버튼**
- 📄 **결과가 바로 보이는 화면**
- 🌐 **웹 브라우저에서 누구나 사용 가능**

따로 사용 설명도 필요 없이, 모두가 쉽게 사용할 수 있는 형식으로 내 코드를 변신시켜주었어요.

**즉, Gradio는 내가 구현하고 싶은 기능을 코드 몇 줄만으로 웹 데모 형식으로 만들어주는 도구입니다.**

## 2️⃣ 왜 Gradio를 사용할까?

Gradio를 사용하는 목적은 딱 하나입니다.

> '코드'가 아니라 '화면'으로 보여주자

### 이런 상황에 특히 좋아요 👇

#### 👩‍🏫 수업·강의용

- 학생들이 코드를 몰라도 버튼만 누르면서 AI 동작을 직접 체험할 수 있음
- LLM, 이미지 모델, 음성 모델 설명용으로 정말 많이 쓰임

#### 🚀 빠른 프로토타입 제작

- 모델 개발 후 즉시 데모를 만들어 팀원들과 공유할 수 있음
- 복잡한 웹 개발 없이 몇 분 안에 인터페이스 구축이 가능

#### 💡 LLM 기반 서비스 제작

- 터미널이 아닌 웹 화면으로 사용자와 상호작용할 수 있음
  - 챗봇, 문서 분석, 이미지 생성 등 다양한 AI 서비스 제작에 적합

#### 🤝 비개발자와의 협업

- 기획자, 디자이너, 도메인 전문가가 직접 모델을 테스트할 수 있음
- 통계 등을 보기 쉽게 정리할 수 있음

## 3️⃣ Gradio로 무엇을 만들 수 있을까?

Gradio는 **입력 → 처리 → 출력** 구조만 있으면 거의 다 가능합니다.

### 대표적인 예시

- 💬 **텍스트 → 텍스트**: 챗봇, 번역기, 요약기, 감정 분석
- 🖼️ **이미지 → 텍스트**: 이미지 설명, OCR, 객체 인식
- ✍️ **텍스트 → 이미지**: Stable Diffusion 같은 생성 모델 데모
- 🎤 **음성 → 텍스트**: 음성 인식(STT)
- 📝 **텍스트 → 음성**: 음성 합성(TTS)
- 🎨 **이미지 → 이미지**: 스타일 변환, 이미지 편집
- 📊 **테이블 → 시각화**: 데이터 분석 및 차트 생성

### HuggingFace Spaces

[Spaces - Hugging Face](https://huggingface.co/spaces)

👉 **Hugging Face Spaces**는 \
전 세계 AI 개발자들이 **자신의 모델/앱을 웹에서 직접 체험 가능한 형태로 배포하는 플랫폼**입니다.

쉽게 말해

> **AI 모델을 '웹 데모 서비스'처럼 공개할 수 있는 공간**

입니다.

- 복잡한 배포 과정 없이 \
  👉 모델 + 웹 인터페이스를 곧바로 실행 가능
- 누구나 링크만 열면 \
  👉 브라우저에서 체험 가능
- 코드나 서버 관리를 몰라도 \
  👉 즉시 데모 공유 가능

👉 자세한 예시는 [아카이브](/archives)를 확인하세요!

🚧 실제로는 아주 복잡한 AI 알고리즘이 있어요.

- 이미지 인식
- 옷 분리/합성
- 스타일 변환 모델

혼자서는 코드 실행도 어렵고, \
웹 서비스로 만들려면 HTML/CSS/JS까지 수십 줄이 필요합니다.
그렇지만 Gradio가 있다면, 코딩을 배운 적 없는 사람도 이렇게 모델을 사용할 수 있어요.

💡 HuggingFace Spaces에 들어가, 위의 모델 말고도 다양한 모델을 사용해보세요!

## 4️⃣ Gradio의 기본 아이디어

Gradio는 아래 구조를 그대로 웹으로 옮깁니다.

```
입력(Input) → 함수(Function) → 출력(Output)
```

### 예시

- **입력**: 사용자가 쓴 문장
- **함수**: AI 모델이 처리하는 함수
  - **출력**: 모델의 답변
